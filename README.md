# Sea Time: עיצוב מחדש לאתר (טיוטה)

כאן נמצאת כל העבודה שנעשתה ב-22.10.2026 על עיצוב מחדש לעמוד הבית של sea-time.co.il. זו טיוטה לבחינה, לא האתר החי.

## שתי גרסאות
| תיקייה | מה זה |
|---|---|
| `site/` | **הגרסה המומלצת.** עמוד בית רגיל, בלי אפקט גלילה: וידאו מלא בפתיחה, השוואת קורסים (משיט 30 → יוון → 7 מטר), וידאו מיוון, המייסדים, ביקורות גוגל, ותפריט עם כל עמודי האתר הקיים. זו הגרסה שבקישור: https://undark-ai.github.io/seatime-preview/ |
| `site-scroll/` | גרסה עם אפקט גלילה (scroll-craft): ההירו נגלל, מסלול משיט 30 נע מימין לשמאל, ו"חלון" שנפתח ליוון. |

## איך לפתוח מקומית
```bash
cd site && python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## מסמכים
- `docs/BRIEF.md`: הבריף והעובדות מהאתר הקיים
- `docs/`: דוחות הבנייה וההחלטות של כל סבב (VERDICT, BUILD-REPORT)
- `site/data/site-pages.json`: רשימת כל 43 העמודים באתר הקיים והקבוצות שלהם

## שאלות פתוחות לבעלים
1. האם יש מספר וואטסאפ? (באתר אין)
2. גיל מינימום למשיט 30: 18 או 17.5? (באתר מופיעים שניהם)
3. אפשר לפרסם מחיר ל-7 מטר וליוון?
4. איפה צולמו תמונות "יוון"? (הווידאו בדסקטופ הוא מקורס ספטמבר 22, ככל הנראה מילוס)
5. אין באתר הקיים מדיניות פרטיות, ו-10 עמודי "חומרי הדרכה" + עמוד היאכטה "קלימרה" שבורים.
